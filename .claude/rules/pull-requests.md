# Pull requests created by Claude

When Claude creates a pull request, mark it as Claude-generated:

- Start the PR title with the 🤖 icon, followed by a space, e.g. `🤖 feat: add clothing advice to weather popup`.
- Keep the "🤖 Generated with [Claude Code](https://claude.com/claude-code)" line at the end of the PR description.

Do not add the icon to PRs that were not created by Claude. Do not rename existing PRs unless asked.
